Событийно-ориентированная архитектура - паттерн, при котором компоненты системы взаимодействуют через асинхронные события.

**Бизнес-сценарии:**
- Реализация сложных бизнес-процессов (лечение → оплата → страхование)
- Снижение связанности между доменами
- Поддержка реального времени в аналитике

**Статус:** Пилотируется для интеграции между доменами
