React - современная библиотека для построения пользовательских интерфейсов. Используется для создания портала самообслуживания и обновления клиентских интерфейсов вместо устаревшего PowerBuilder.

**Бизнес-сценарии:**
- Улучшение UX для операторов клиник, повышение эффективности работы
- Быстрое внедрение новых функций в портале самообслуживания
- Единый стек технологий для frontend-разработки во всех доменах

**Статус:** Активно используется в новом портале самообслуживания
