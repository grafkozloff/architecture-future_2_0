Kong - инструмент для реализации API Gateway. Используется для маршрутизации и защиты API.

**Бизнес-сценарии:**
- Безопасная публикация API для внутренних и внешних потребителей
- Rate limiting и контроль нагрузки на сервисы
- Централизованная точка мониторинга API-трафика

**Статус:** Основной инструмент для управления API в каждом домене
