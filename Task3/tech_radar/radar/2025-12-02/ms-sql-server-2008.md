Microsoft SQL Server 2008 - устаревшая версия СУБД, используемая в текущем монолитном DWH.

**Проблемы:**
- Низкая производительность на сотнях терабайт данных
- Риски безопасности из-за отсутствия обновлений
- Неподдерживаемость современными инструментами
- Высокая стоимость лицензирования

**План замены:** Миграция на облачные и распределённые хранилища данных
