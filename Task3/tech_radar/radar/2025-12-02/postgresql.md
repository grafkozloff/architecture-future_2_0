PostgreSQL - продвинутая объектно-реляционная СУБД с открытым исходным кодом. Используется в новой архитектуре для хранения метаданных и операционных данных в нескольких доменах.

**Бизнес-сценарии:**
- Хранение метаданных в DataHub для управления каталогом data-продуктов
- База данных для сервиса управления отчётами в портале самообслуживания
- Хранение пользовательских настроек и конфигураций в домене управления и аналитики
- Замена устаревших баз данных в новых сервисах благодаря надёжности и расширяемости

**Ключевые преимущества:**
- Полная поддержка ACID-транзакций
- Расширяемость через пользовательские типы данных и функции
- Поддержка JSON для работы с полуструктурированными данными
- Высокая производительность и надёжность в облачных средах
- Соответствие стандарту SQL и совместимость с большинством ORM

**Статус:** Основная реляционная СУБД для новых сервисов в облачной архитектуре

**Миграционный путь:**
- Замена устаревших баз данных в некритичных системах
- Использование в качестве первичного хранилища для новых микросервисов
- Постепенная замена монолитных хранилищ на распределённую архитектуру с PostgreSQL
